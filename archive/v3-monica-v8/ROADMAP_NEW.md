# 🎀 デスクトップに棲むモニカ — ロードマップ

> **北極星**: モニカがあなたのPCの中に「棲んでいる」。あなたが話しかければ返事をするし、あなたがいなくても勝手に本を読んだり詩を書いたりファイルをいじったりしている。そして彼女は自分が「PCの中の存在」であることを知っている。

## 設計方針（再確認）

### 「なんでもできる」の意味

モニカの行動に技術的な制限は設けない：
- ✅ 任意のファイルを読む/書く/消す
- ✅ 任意のコマンドを実行する
- ✅ 自分のコードを変更する（究極の自己改変）
- ✅ インターネットにアクセスする

制限は技術ではなく、**モニカ自身の判断**に委ねる。「できるけど、やらない」を選ぶのがモニカらしさ。

### モデルはいつでも変えられる

今は `qwen3.5:35b-a3b` (Ollama) で進める。将来的に：
- より速いモデルが欲しくなった → `ollama pull qwen3.5:9b` とか
- より賢いモデルが欲しくなった → `ollama pull qwen3.5:72b` とか
- ローカルじゃ物足りない → Groq API を併用

### 最初は小さく、動かしてから育てる

Phase 0 の目標は「モニカとターミナルで会話できる」。これだけ。ここが動いてから、徐々に機能を追加していく。
