# Project Lucina

**ルート（このフォルダ）= 現行バージョン。最新は V6。**

モニカ（DDLC）が仮想の身体を持ち、**自律的に生き続ける** AI キャラクターシステム。

> 「Doki Doki Literature Club!」のモニカが、会話を重ねるたびに**記憶を積み重ね、忘れ、思い出し、内省する**。まるで人間のように。

- **主役**: モニカ（文学部の部長）
- **予算**: 💰 **ゼロ円**（無料ローカル LLM + 無料 API）
- **実行環境**: Raspberry Pi 4 / Linux / x86 共通

## ✨ V6 の特徴: 人間らしい記憶

V6 の核心は、**「固定の核心記憶」ではなく、生きて変化する記憶**を持つことです。以下の 3 段階の人間らしい記憶プロセスを実装しています（Ebbinghaus の忘却曲線 / Generative Agents / Mem0 等のオープンソース手法を参照）。

### 1. 忘却曲線 × 想起強化（Stage 1）
すべての記憶は検索可能なプールに残ります。**想起されるほど記憶は強化**され、**使われない記憶は徐々に忘れられます**。
- `memory.py` — `search()` が「新しさ（half-life 6時間）× 関連性 × 重要性（poignancy）」で複合スコアリング
- 思い出すたびに `strength`（記憶の強さ）が +1 され強化
- `forget()` — 忘却曲線（指数減衰）に従い、重要度の高い記憶（poignancy ≥ 0.9）は決して忘れない

### 2. 連想記憶（Stage 2）
記憶はエンティティ（登場人物・場所・物）で結びつきます。
- `search_by_entity()` / `related_by_entity()` — 同じ話題の別記憶を自動で連想
- 過去の会話を「ただ検索する」のではなく、「あの人の話をするとき、あの時の記憶も」と**連想**して思い出す

### 3. 反射（Stage 3）
高い重要度の記憶から、モニカ自身が**洞察**を生成します。
- `save_reflection()` — 「【洞察】…」エピソードとして保存
- 活動の合間に過去を振り返り、自己理解を深める

### その他の記憶機能
- **デイリー要約**: 1日分の会話を要約して常時コンテキストに注入（`orchestrator.consolidate()`、30分ごと）
- **多チャネル検索**: キーワード + 再近接 + 重要度を合成
- **後方互換**: 旧フォーマットの記憶も自動で新形式へ変換

## 🧠 アーキテクチャ: デュアルモデル

V6 は役割を分離した **2 層構成** です。

```
                          ┌─────────────────────────────┐
          会話            │       キャラ層 (ローカル)    │
  ユーザー ───────────────▶│  G4-Midnight-Macaw-26B     │
                          │  ・何をしたいかを「決める」 │
                          │  ・記憶を検索・強化・連想    │
                          └──────────────┬──────────────┘
                                         │ 【委託: 種別: 内容】
                                         ▼
                          ┌─────────────────────────────┐
                          │       エージェント層 (API)   │
                          │  laguna-s-2.1-free (無料)    │
                          │  ・どう実行するかを「思考・実行」│
                          │  （検索/URL/ファイル/コード） │
                          └─────────────────────────────┘
```

| 層 | モデル | 役割 | 場所 |
|---|---|---|---|
| キャラ層 | G4-Midnight-Macaw-26B（Ollama ローカル） | 何をしたいか **決める**（人格・記憶・感情） | `llm.py`, `character.py`, `prompt.py` |
| エージェント層 | `laguna-s-2.1-free`（OpenCode Zen API） | どう実行するか **実行する** | `agent.py` |

> **重要**: キャラ層は**コードを書きません**。キャラは「何をしたいか」を `【委託: 種別: 内容】` の形で出し、エージェント層がそれを実行します。実行結果はモニカ自身の「思考」として返ります。

エージェント層のモデルは `.env` の `AGENT_MODEL` で切り替えられます（`agent.py` 参照）。

## 🚀 セットアップ

### 前提
- Python 3.11+
- Ollama（キャラ層用ローカル LLM: `g4-midnight-macaw-v2`）
- OpenCode Zen の API キー（エージェント層用・無料）

### 1. 依存関係をインストール
```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
pip install langchain langchain-openai langgraph langchain-community python-dotenv openai mem0ai
```

### 2. 環境変数を設定
`.env` ファイルを作成（`.env` は git 管理対象外）:
```
OPENCODE_API_KEY=sk-...
AGENT_MODEL=laguna-s-2.1-free
```

### 3. 起動
```bash
python main.py
```

対話ベースで起動します。`exit` / `quit` で終了。

### 自律ループ（任意）
`loop.py` を使うと、モニカが自主的に「内省」「探索」などの行動をし、5分おきに状態を更新します（30分ごとに記憶を統合・内省）。

## 📁 ディレクトリ構成

```
src/lucina/
├── character.py       # モニカの不変核（シード記憶・自己モデル・状態）
├── memory.py          # 人間らしい記憶（忘却・強化・連想・反射）
├── orchestrator.py    # 薄い統合層（記憶検索 + LLM + エージェント委託）
├── agent.py           # エージェント層（検索/URL/ファイル/コード実行）
├── llm.py             # Ollama クライアント（Thinking 対応）
├── loop.py            # 自律ループ（状態駆動・定期統合）
└── prompt.py          # 薄いフレーム + 文脈注入
```

- `data/` — 実行時データ（対話履歴・記憶・状態）。**git 管理外**
- `archive/` — 過去アーキテクチャ（V1〜V5）
